# Honorverse: Tactical (pracovní název „Wall of Battle")

Browserová taktická simulace vesmírných bitev ze světa Honor Harringtonové
(David Weber). Kampaň o 10 misích, důraz na věrný fyzikální model
(impelerové klíny, rakety s laserovými hlavicemi, vrstvená obrana),
minimalistická vektorová grafika.

**Stav projektu:** fáze návrhu.

📄 **[Rešerše světa a kompletní herní návrh](docs/GAME_DESIGN.md)** —
fyzika boje v Honorverse, klíčová čísla pro simulaci, návrh 10 misí
se zvraty, technická architektura (TypeScript + Canvas + Web Worker)
a plán vývoje po fázích.
